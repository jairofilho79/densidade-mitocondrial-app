# Quebrar o tempo sentado

**Melhor estímulo "de graça".** Interromper o sentar com 2–5 min de movimento leve a cada 20–30 min: glicose/insulina pós-prandial SMD ≈ −0,55 (Loh 2020). Escada 1–3 min ("exercise snacks"). Para quem programa, é o input mais relevante do dia.

**Faces:** blocos >60–90 min sentado sem pausa → pior · pausas a cada 20–30 min → melhor · mesa em pé sem andar → pouco.

**Registro:** nível 1 "quantas vezes levantei"; nível 2 "maior bloco sentado"; nível 3 passos/dia ([[indicadores/passos-por-dia]]).
