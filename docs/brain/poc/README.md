# PoC conversacional

Claude = o app. Usuário = uma pessoa real registrando o dia (vago, incompleto, como é na vida).

## Rodada
1. **Registro** — o usuário conta o dia do jeito que contaria a um amigo.
2. **Resposta do app** — o que dá para dizer com confiança, o que não dá, e *uma* pergunta que mostre o que a pessoa ganharia respondendo (ADR-002).
3. **Bastidores** — fora do personagem: que dado foi necessário, que conceito foi usado, que ponto ficou solto.
4. **Colheita** — atualizar notas do brain e [[../perguntas-abertas]].

## Registro de sessões
`sessoes/YYYY-MM-DD-NN.md` com as 4 partes acima.

## O que estamos tentando descobrir
- Os **níveis de riqueza** de cada domínio e o que o app diz em cada um.
- Qual pergunta de volta faz a pessoa *querer* registrar mais.
- A **unidade de tempo** do registro ([[../perguntas-abertas#Q8]]).
- Quais indicadores objetivos a pessoa realmente tem ([[../perguntas-abertas#Q2]]).
