# ADR-003 — Antes de código, uma PoC conversacional

**Decisão:** nenhum sistema agora. Claude faz o papel do app; o usuário faz o papel de uma pessoa real registrando seu dia. O que sobreviver às rodadas vira nota no brain; só depois vira spec e código.

**Por quê:** os conceitos ainda não estão definidos na prática. Modelar dados antes de saber o que o app precisa *dizer* produz um modelo errado.
