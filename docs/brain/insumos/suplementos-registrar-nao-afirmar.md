# Suplementos: registrar, não afirmar

Lista do que aparece no marketing de "mitocôndria" com evidência humana fraca ou nula. O app **registra** para a pessoa cruzar, **não afirma** efeito.

| Item | O que a evidência mostra |
|---|---|
| Creatina | só com treino de força (moderada) — fora disso, nada mitocondrial |
| CoQ10 suplementar 100–200 mg | glicemia −5 mg/dL, HOMA-IR −0,69, "very low certainty" (Liang 2022) |
| NR / NMN | respiração mitocondrial *não* muda em obesos |
| Urolitina A | desfechos primários não atingidos |
| Resveratrol | inconsistente |
| Magnésio, L-carnitina | só em deficiência |
| Vitamina D | só em deficiência; prevenção de DM2 modesta (HR 0,85), D2d ns |
| Ferro, B12 | **corrigir deficiência sim; empilhar sem exame não.** B12 é flag para quem usa metformina |
| Vitamina C >1000 mg + E 400 UI | **anulam** a adaptação do treino (Ristow 2009) — face ruim |
| Chá verde | HOMA-IR/glicemia, efeito pequeno (Liu 2013, 17 RCTs) — moderada |

Regra: sem exame (ferritina, B12, 25(OH)D), metade disso é palpite (→ Q15).
