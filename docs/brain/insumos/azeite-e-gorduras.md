# Azeite extra-virgem e qualidade das gorduras

PREDIMED: dieta mediterrânea com azeite EV → diabetes −40%. Troca saturada → insaturada: KANWU (sensibilidade à insulina +~10%), LIPOGAIN (menos gordura visceral). Sparks 2005: 3 dias de dieta muito gordurosa → PGC-1α −20%.

**Faces:** saturada alta crônica → PGC-1α cai · insaturada (azeite, oleaginosas, peixe) → melhora · gordura trans → zero, sem faixa.

**Registro:** "que gordura cozinhou/usou hoje?" — azeite / manteiga-banha / óleo de soja / industrializada.
