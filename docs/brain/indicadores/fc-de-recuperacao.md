# FC de recuperação em 1 min

FC no fim do último tiro menos FC 1 min depois. Queda ≤12 bpm é anormal (Cole 1999; Vivekananthan 2003); melhora com treino. Precisa de sensor (nível 4). Cruza com [[resistencia-no-hiit]].

→ [[pesquisa/2026-09-14-outputs-medicao]]

## Nível (triagem 2026-09-14 · ADR-007)
**fronteira · registro.** Corte ≤12 bpm é prognóstico clínico sólido, mas como marcador de adaptação em sedentários os dados são insuficientes (Casanova-Lizón 2022).
