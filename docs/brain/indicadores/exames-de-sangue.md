# Exames de sangue (faixa C)

Repetir a cada 12 semanas, não antes. Cortes para brasileiros:

| Exame | Corte | Nota |
|---|---|---|
| Glicemia de jejum | <100 normal; 100–125 pré | |
| HbA1c | <5,7% | meia-vida 35 dias — não repetir antes de 8–12 sem |
| Insulina jejum → HOMA-IR | >2,7 (BRAMS) | o único que mede *resistência* |
| TG/HDL | >2,6 H / >1,7 M (ELSA-Brasil) | proxy barato de RI |
| Ferritina + saturação | ver [[../conceitos/ferro-e-ferritina]] | alta no público-alvo |
| 25(OH)D, B12 | só para corrigir deficiência | B12 se metformina |
| Pressão arterial | <120/80 | HIIT baixa PA média −7% |

Sem esses, metade dos insumos "bons" é palpite (→ Q15).
